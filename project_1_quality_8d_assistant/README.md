# Project 1 — AI Quality & 8D Assistant

## Business problem

Quality engineers often spend significant time converting unstructured field/production complaints into structured problem statements, containment actions, root-cause hypotheses, and corrective-action plans.

## AI opportunity

Use GenAI-style structured extraction and reasoning to create a first draft while keeping the engineer in control.

## Workflow

Complaint
→ structured extraction
→ problem statement
→ 5-Why hypotheses
→ corrective-action candidates
→ 8D draft
→ human validation

## Example value

If 20 engineers each spend 2 hours/week preparing and reviewing initial quality summaries, reducing preparation time by 40% can recover substantial engineering capacity.

## Governance

- AI output is a draft.
- Root cause is never accepted automatically.
- Safety/critical quality decisions require human approval.
- Source evidence should be retained in a production implementation.
