# Project 3 — Low-Code Manufacturing AI Agent

## Business problem

Manufacturing troubleshooting often requires multiple manual steps:

- read the complaint
- identify the failure category
- find likely causes
- determine diagnostic checks
- document the action
- notify the right team

## AI-enabled workflow

Complaint
→ classify
→ retrieve guidance
→ identify likely causes
→ recommend checks
→ generate action record
→ human approval

## Low-code mapping

This Python demo represents the logic that can be implemented with:

- Google AppSheet
- Google Workspace Studio
- Microsoft Power Apps
- Microsoft Power Automate

## Example data flow

Form submission
→ AI task
→ classification
→ knowledge lookup
→ recommendation
→ approval
→ ticket/task creation
→ dashboard

The key professional skill demonstrated is translating an operational process into an AI-enabled workflow rather than building software for its own sake.
