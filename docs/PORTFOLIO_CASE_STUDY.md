# Portfolio Case Study Template

## 1. Business problem

Describe the operational pain in measurable terms.

## 2. Current state

Document the process, users, systems, manual work and bottlenecks.

## 3. AI opportunity

Explain why AI is appropriate and what AI capability is being used.

## 4. Solution

Show:

`User → Input → AI → Data/Knowledge → Recommendation → Human approval → Action`

## 5. Prototype

Include screenshots, sample inputs and outputs.

## 6. Business value

Track:

- hours saved
- cycle-time reduction
- quality improvement
- rework reduction
- adoption
- user satisfaction

## 7. Governance

Document:

- data classification
- permissions
- human-in-loop
- validation
- auditability

## 8. Scale plan

Describe how the pilot could move into an enterprise platform.
